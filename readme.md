# Personal Portfolio Website - Amir Aspad

This is a simple, elegant, and fully static personal portfolio website built with HTML, CSS, and JavaScript.  
The website showcases my skills, experience, and contact information, and includes both dark and light themes with a toggle switch.

## 📌 Live Demo

[Click here to visit the live site](https://amir-aspad.github.io)

## 🚀 Features

- Responsive single-page layout
- Dark/Light mode switcher with icon change
- Categorized skill section with animated gauge meters
- Smooth scroll to sections
- About Me and Contact Me sections
- Clean and readable design with Persian font support

## 🛠️ Technologies Used

- HTML5
- CSS3 (with custom styling)
- JavaScript (vanilla)
- SVG for skill gauges
